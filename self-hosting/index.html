Install and run

Availability

Fiscal Fox is in development. Its source is not public and there is no public release yet. This guide describes how an installation runs, for people who already have a copy of Fiscal Fox.

Fiscal Fox runs on your own infrastructure with Docker Compose. One installation can hold several organizations, each with its own separate financial data.

What runs

ServiceWhat it does
Webnginx serving the browser app.
APIThe REST API, sign-in, permissions, and webhook endpoints.
WorkerBackground jobs: email delivery, receipt reading, calendar sync, report exports, and generated files.
PostgreSQLThe authoritative ledger. Every organization's data is separated with row-level security.
ValkeyThe job queue.
SeaweedFSS3-compatible storage for receipts, contracts, and immutable generated files.
MailpitCatches outgoing email during local use. Replace it with a real SMTP service in production.
Database owner and migrateOne-shot services that set database ownership and apply migrations before the API starts.

The API records audit events and background work in the same transaction as the business change. Workers pick up that work once and write immutable file records with their SHA-256 fingerprints. Provider credentials are optional: an integration that is not configured fails clearly instead of pretending to succeed.

Requirements

  • Node.js 26
  • Corepack with pnpm 11.13.1
  • Docker with Compose
  • curl

Start a local installation

From the Fiscal Fox directory:

cp .env.example .env
. scripts/load-env.sh
corepack pnpm install --frozen-lockfile
docker compose config --quiet
docker compose up -d --build --wait

scripts/load-env.sh must be sourced, not executed. It exports the .env values into the current shell, so host-side commands such as migrations use the same configuration that Compose reads.

Once the stack is healthy, open:

ServiceAddress
Web apphttp://localhost:5173
API healthhttp://localhost:3000/health
API documentationhttp://localhost:3000/api/docs
Mailpithttp://localhost:8025
SeaweedFS S3http://localhost:8333

On a new installation, the first person to sign up creates the first local account and organization. Everyone else joins through an invitation. See Getting started.

Warning

The local Compose setup uses development secrets and plain HTTP. Replace every development secret before any non-local deployment. Production needs TLS, secure cookies, trusted origins, external secret management, restricted network access, and tested backups. See the Production checklist.

What's included

  • Email and password sign-in with passkeys, and first-user onboarding.
  • Organization memberships with role and permission checks, enforced by PostgreSQL row-level security.
  • A Dutch chart of accounts, VAT codes, fiscal periods, journals, XAF 4.0 exports, UBL documents, CSV import dry runs, and reports.
  • The quarterly Dutch VAT return (boxes 1a to 5c, filing amounts and deadline) with ICP, OSS, and KOR checks.
  • A widget dashboard, financial statements, cash flow, and customer, supplier, product, cost, and trip insights.
  • Sales documents, expenses (including drafts that wait for their receipt), draft contacts, Stripe Connect payments, contracts, time, trips, calendar and maps connections, and immutable generated files.
  • An OpenAPI 3.1 description of the REST API. See API.

Not included

Fiscal Fox does not provide a bank connection or feed, hosted business email, native mobile or desktop apps, Peppol transport, or direct tax filing. XAF and UBL exports support hand-off workflows; they are not filing or delivery services.
