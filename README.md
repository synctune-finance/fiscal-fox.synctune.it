# Fiscal Fox website

The product website and user documentation for
[fiscal-fox.synctune.it](https://fiscal-fox.synctune.it): a landing page, the
user manual and the self-hosting guide for Fiscal Fox. Plain HTML and CSS with
locally bundled images. No JavaScript, web fonts, dependencies, install
command or build step.

- [Preview and Pages deployment](docs/deployment.md)
- [Content, layout, checks and assets](docs/maintenance.md)

Site source lives at the repository root, `manual/` and `self-hosting/`.
GitHub Actions checks, packages and deploys site changes on `main`.
